Checking a built board

  1. Power up with no microphone, phantom off and gain at minimum. Both emitter nodes should read about +0.65 V and both output nodes (the Q3 and Q4 emitters) about −8.8 V. ESP notes that a reading far from these means a construction mistake, and a mismatch between the halves costs hum rejection.
  2. Turn the gain up with nothing plugged in. Some hiss is normal: it is R12 and R13’s own noise, and it drops once a low-impedance microphone is connected.
  3. Plug in a dynamic microphone and check level and polarity at J5.
  4. Only then try phantom, with a condenser microphone and the output turned down.

Never into a phantom-powered input

ESP warns that 48 V on the output destroys the op amp. When testing, plug the output into a line input, never a microphone input with phantom on.
