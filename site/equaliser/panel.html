The front panel

Controls, legend and hole positions for the equaliser, on the same 1.5 inch 500-series faceplate as the rest of the desk.

Nothing here is designed yet

The equaliser module has no schematic, no netlist and no bill of materials. This section is a template that mirrors the structure of the compressor documentation, so the shape of the work is visible before the work starts. Every figure below is deliberately blank rather than guessed.

What is already fixed

The panel outline does not depend on the circuit. Every module in the desk shares it.

DimensionValue

What is not

Control count, control type and legend all follow from the circuit. The compressor's panel is generated by a script that takes one definition of the controls and produces the mockup, a 1:1 technical drawing and a DXF, checking every hole for clearance on each build. The same script will produce this panel once there is a control set to give it.
